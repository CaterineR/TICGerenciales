# TIC Gerenciales — Proyecto Integrador

Materiales interactivos del Proyecto Integrador de TIC Gerenciales (UNIMETA).

## Experiencia 3D / Realidad Aumentada

Abre: https://cateriner.github.io/ticgerenciales/

Explora en 3D los sistemas, el conocimiento y la decisión gerencial de una "empresa inteligente". Si tu celular es compatible (Chrome en Android con ARCore), también puedes verlo en Realidad Aumentada real, tocando el botón "Ver en Realidad Aumentada".
